# 🟩 Вордли — Игра в слова на русском

Популярная игра-головоломка «Вордли» (Wordle), адаптированная для русского языка, прямо в вашем браузере! Угадывайте слова из 5 букв за 6 попыток, соревнуйтесь сами с собой и тренируйте словарный запас.

![Вордли баннер](https://img.shields.io/badge/Status-Active-success) ![JavaScript](https://img.shields.io/badge/1%25-JavaScript-yellow) ![Tailwind CSS](https://img.shields.io/badge/Styles-Tailwind%20CSS-blue)

## 🎮 Особенности игры

* **Полная поддержка русской буквы «Ё»**: игра корректно распознает слова с буквой «Ё» как в словаре, так и при вводе/отображении правильных ответов.
* **Адаптивный дизайн**: одинаково хорошо работает как на экранах компьютеров, так и на мобильных телефонах.
* **Виртуальная экранная клавиатура**: динамически меняет цвета клавиш (зелёный — буква на своём месте, жёлтый — буква есть в слове, серый — буквы нет).
* **Поддержка физической клавиатуры**: можно набирать слова прямо с клавиатуры компьютера.
* **Обширный словарь**: тщательно подобранная база существительных длиной ровно в 5 букв.
* **Встроенные правила**: удобное модальное окно с подробным объяснением правил игры.

## 🚀 Как запустить игру локально

Проект состоит из одного самодостаточного HTML-файла, поэтому для его запуска не нужно устанавливать Node.js, Webpack или настраивать сервер.

1. Скачайте репозиторий (или скопируйте код из файла `index.html`).
2. Откройте файл `index.html` в любом современном браузере (Google Chrome, Firefox, Edge, Safari).

---

## 🕹️ Как играть

1. Угадайте загаданное слово за **6 попыток**.
2. Каждая попытка — это слово на русском языке длиной ровно **5 букв** (вводите существующие существительные).
3. После ввода слова цвет плиток изменится:
   * 🟩 **Зелёный** — буква есть в слове и стоит на **правильном** месте.
   * 🟨 **Жёлтый** — буква есть в слове, но стоит на **другом** месте.
   * ⬛ **Тёмно-серый** — этой буквы **нет** в загаданном слове.
